# Hate Speech Detection using Machine Learning

This project detects and classifies text into:

- Hate Speech
- Offensive Language
- Neutral Speech

The model uses TF-IDF Vectorization and Logistic Regression.
A Gradio interface is provided for interactive text prediction.

## Technologies Used

- Python
- Natural Language Processing
- Scikit-learn
- TF-IDF
- Logistic Regression
- NLTK
- Gradio
- Pandas
- NumPy
